# 🪲 DeBugify – Bug Tracking Dashboard

**DeBugify** is a modern and interactive **bug tracking dashboard** that helps students and developers efficiently **track, manage, and resolve bugs**.  
Built using **HTML, Tailwind CSS, JavaScript**, and **Chart.js analytics**, it offers sleek visuals and persistent data storage.

---

## 🪲 Tagline

“DeBugify — Debug Smarter. Code Better.” 💡✨

---

## 🚀 Features

- ✅ Add, edit & delete bugs  
- 📌 Track Status: To Do → In Progress → Done  
- 🩺 Severity Levels: Critical / Medium / Low  
- 📊 Analytics Dashboard (Chart.js)
  - Severity distribution chart
  - Status progress chart  
- 💾 LocalStorage data persistence  
- 📱 Responsive UI using Tailwind CSS  
- ♻️ Scalable architecture for backend integration later  

---

## 🧩 Tech Stack

| Layer | Technology |
|------|------------|
| Frontend | HTML, Tailwind CSS, JavaScript |
| Charts & Analytics | Chart.js |
| Local Storage | Browser LocalStorage |
| Future Backend | Firebase / Node.js + Express / MongoDB |
